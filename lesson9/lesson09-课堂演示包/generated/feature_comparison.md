# 自主实践一：更换特征集对客户分群的影响

> 数据：课程提供的**模拟客户数据** `mall_customers_sim.csv`（300 位客户），非真实银行业务数据。原始数据未被修改。

## 一、实验设置

| 实验 | 特征集 | 预处理 | 聚类参数 | inertia_ |
|---|---|---|---|---|
| 实验一 | income + balance | StandardScaler | KMeans(n_clusters=4, random_state=42, n_init=10) | 45.17 |
| 实验二 | income + balance + age | StandardScaler | KMeans(n_clusters=4, random_state=42, n_init=10) | 104.93 |

## 四、两组分区一致性

- 调整兰德指数 **ARI = 0.7270**（同簇编号已按收入中心排序对齐）。
- 交叉表（行=实验一，列=实验二；数值为人数）：

|---|---|---|---|---|
| 簇 0 | 121 | 3 | 2 | 0 |
| 簇 1 | 0 | 54 | 69 | 0 |
| 簇 2 | 0 | 0 | 0 | 26 |
| 簇 3 | 0 | 0 | 1 | 24 |

## 五、加入 age 后分群的变化

- 簇规模分布：实验一（降序）[126, 123, 26, 25] → 实验二（降序）[121, 72, 57, 50]。
- 两组划分的一致程度 ARI = 0.7270；编号已对齐，但分区并非简单平移。
- 具体变动（按交叉表自动识别）：
  - 实验一簇 1（123 人）被拆分到：54 人（实验二簇 1）、69 人（实验二簇 2），最大一块仅占 56.1%
  - 实验二簇 3（50 人）由实验一的簇 2、3 合并而来
- 各簇平均年龄极差几乎不变（实验一 26.09 岁 → 实验二 26.15 岁），说明年龄主要改变的是簇的切分位置，而不是把年龄差异整体拉大。
- 实验一的簇本质上只按「收入-余额」二维位置切分，年龄只作为事后描述；实验二让 age 直接参与距离计算，标准化后年龄与收入、余额等权，因此同一个资产层内部会再按年龄段分开。

## 六、特征选择对业务含义的影响

- **实验一（income + balance）**：客群定义是纯资产维度——「高净值 / 中等 / 低净值」。解读直接，适合做资产分层、产品配置与额度策略；但同簇内可能混杂不同人生阶段的客户，营销话术难以统一。
- **实验二（income + balance + age）**：客群同时带上生命周期标签——「年轻高潜」「中年稳健」「年长高净值」等。适合做生命周期营销（首卡、家庭配置、养老规划），但簇边界不再严格等价于资产等级，不能直接用于资产分层考核。
- 结论：特征选择决定了「业务问题的定义」。要回答资产分层问题，用实验一；要回答客户生命周期经营问题，用实验二；两者不可互相替代。

> 说明：本次两组实验均为 k=4、两/三特征，与课程实践指南的两特征 k=3 口径不同，人数与簇结构不可直接与指南结果对比。
